# MegaHeater2

Мікроконтролерна система керування автономним дизельним обігрівачем.

## Апаратна платформа

| Компонент | Деталь |
|-----------|--------|
| MCU | Arduino Mega 2560 (ATmega2560, 256 KB Flash, 8 KB RAM) |
| Дисплей | ST7789 TFT 320×240, підключення через SPI |
| Енкодер | Ротаційний енкодер з кнопкою |
| Термопари | MAX6675 × 3 (K-type, SPI) |
| Датчик впуску | DS18B20 (One-Wire) |
| Датчик середовища | AHT20 (температура + вологість, I2C) + BMP280 (тиск, I2C) |
| Датчик струму | ACS712F 20A (вимірювання струму свічки) |
| Дільник напруги | Резисторний дільник R1=30 кОм, R2=10 кОм → Vmax≈20 В |

| Адреса | Сенсор |
|--------|--------|

### One-Wire
| Пін | Сенсор |
|-----|--------|
| 23 | DS18B20 — повітря на вході (холодне) |

### Аналогові входи
| Пін | Призначення |
|-----|-------------|
| A0 | Дільник напруги живлення (≤20 В через дільник R1=30к/R2=10к) |
| A1 | ACS712F 20A — струм свічки запалювання (0A → 2.5V / ADC≈512; ~20.5 ADC/А) |

> **Важливо:** A0 при непідключеному дільнику є плаваючим входом і показує шум. Підключіть 10 кОм на GND при відсутності дільника.

## Режими роботи

| Режим | Опис |
|-------|------|
| **Нагрів** (MODE_HEAT) | Нормальний режим. Вентилятор + насос + свічка під час запуску |
| **Вентиляція** (MODE_VENT) | Тільки вентилятор, насос і свічка не вмикаються |

Режим обирається кнопками BTN_HEAT / BTN_VENT тільки у стані ВИМКНЕНО або ПОМИЛКА.

## Стани обігрівача

```
                          [ignitionTime вичерпано, 1-ша спроба]
                        ┌─────────────────────────────────────┐
                        │                                     ▼
ВИМКНЕНО ─[Toggle]─► ЗАПУСК                             ПЕРЕЗАПУСК
                        │                                     │
               [вихлоп ≥ startFireTemp]            [вихлоп ≥ startFireTemp]
                        │                                     │
                        └──────────► НОРМАЛЬНА РОБОТА ◄───────┘
                                           │   │
                                    [Toggle]   [вихлоп < startFireTemp]
                                           │               │
                                           ▼               ▼
              FAULT ◄─[ignitionTime]─ ОХОЛОДЖЕННЯ ◄── ПЕРЕЗАПУСК (одна спроба)
                                           │
                                  [камера ≤ coolStopTemp]
                                           │
                                           ▼
                                    ВИМКНЕНО / ПОМИЛКА
```

| Стан | Клапан | Свічка | Вентилятор | Насос |
|------|--------|--------|------------|-------|
| ВИМКНЕНО | — | — | — | — |
| ЗАПУСК | Відкрито | Увімкнена (до ignitionTime) | startFanRpm | startPumpRpm (після затримки) |
| ПЕРЕЗАПУСК | Відкрито | Увімкнена (до ignitionTime) | startFanRpm | startPumpRpm (після затримки) |
| НОРМАЛЬНА РОБОТА | Відкрито | — | POWER_TABLE[power] | POWER_TABLE[power] |
| ОХОЛОДЖЕННЯ | — | — | coolFanRpm | — |
| ПОМИЛКА | — | — | — | — |
| ПРОКАЧКА | Відкрито | — | — | MAX (255) |

## Алгоритм запуску

1. Натиснута кнопка Toggle → стан переходить у **ЗАПУСК**
2. Вмикається паливний клапан
3. Вентилятор виходить на `startFanRpm` через ПІД-регулятор
4. Свічка запалювання вмикається
5. Якщо задана `Затримка насоса` > 0 — насос стоїть задану кількість секунд
6. Після затримки насос виходить на `startPumpRpm` через ПІД
7. Через 1000 мс після ввімкнення свічки — перевірка струму ACS712:
   - Якщо струм < `Мін.струм свічки` і налаштування ≠ 0 → **FAULT_IGNITION_OPEN**
8. Якщо температура вихлопу досягає `startFireTemp` → стан **НОРМАЛЬНА РОБОТА**, свічка вимикається
9. Якщо час `ignitionTime` вичерпано і займання не відбулося:
   - Перша спроба → **ПЕРЕЗАПУСК** (повторює кроки 3–8)
   - Друга спроба не вдалася → **FAULT_NO_IGNITION** → **ОХОЛОДЖЕННЯ**

## Алгоритм зупинки

1. Натиснута кнопка Toggle (або спрацювала аварія) → стан **ОХОЛОДЖЕННЯ**
2. Паливний клапан і свічка вимикаються, насос зупиняється
3. Вентилятор виходить на `coolFanRpm` через ПІД
4. Коли температура камери ≤ `coolStopTemp` → стан **ВИМКНЕНО** (або **ПОМИЛКА** якщо причина аварія)

## Алгоритм прокачки

- Режим **Утримання**: насос на MAX при натиснутій кнопці PRIMING, зупиняється при відпусканні
- Режим **Таймер**: насос на MAX протягом заданого часу після натискання кнопки
- Доступна тільки у стані ВИМКНЕНО або ПОМИЛКА
- Паливний клапан відкривається під час прокачки

## ПІД-регулятори

Velocity-form PI (оновлення раз на 1 секунду):

```
Δu = Kp*(e - e_prev) + Ki*e
u[k] = clamp(u[k-1] + Δu, 0, 255)
```

| Параметр | За замовч. | Одиниці |
|----------|-----------|---------|
| Вентилятор Kp | 0.040 | ШІМ/RPM |
| Вентилятор Ki | 0.008 | ШІМ/RPM |
| Насос Kp | 0.400 | ШІМ/RPM |
| Насос Ki | 0.080 | ШІМ/RPM |

## Зарядка акумулятора

Якщо напруга живлення нижче порогу `Поріг зарядки` — вихід CHARGER_PIN переходить у HIGH (ввімкнення зовнішнього зарядника). Перевіряється кожну секунду.

## Таймер автовимкнення

При ввімкненому таймері обігрівач автоматично зупиняється після заданого часу роботи. Налаштовується через меню (увімкнення + тривалість).

## Перелік помилок

| Код | Короткий код | Назва | Умова спрацювання |
|-----|-------------|-------|-------------------|
| 1 | Е:КАМ | ПЕРЕГРІВ КАМЕРИ | tempChamber > maxChamber (за замовч. 310°C) |
| 2 | Е:ВИХ | ПЕРЕГРІВ ВИХЛОПУ | tempExhaust > maxExhaust (за замовч. 380°C) |
| 3 | Е:ЗАП | НЕ ЗАПАЛЮЄТЬСЯ | Вихлоп не досяг startFireTemp за обидві спроби ignitionTime |
| 4 | Е:СКМ | ДАТЧИК КАМЕРИ | MAX6675 повертає NAN (термопара відключена) |
| 5 | Е:СВХ | ДАТЧИК ВИХЛОПУ | MAX6675 повертає NAN (термопара відключена) |
| 6 | Е:НАП | НИЗЬКА НАПРУГА | voltage < voltageMin (за замовч. 8.0 В) |
| 7 | Е:ВАП | ВИСОКА НАПРУГА | voltage > voltageMax (за замовч. 30.0 В) |
| 8 | Е:КОН | АВАРІЙНИЙ КОНТАКТ | SENSOR_EMERGENCY_PIN = HIGH |
| 9 | Е:ПЕР | ПЕРЕЛИВ ПАЛЬНОГО | SENSOR_FUEL_OVERFLOW_PIN = HIGH |
| 10 | Е:БАК | МІНІМУМ ПАЛЬНОГО | SENSOR_FUEL_MIN_PIN = HIGH |
| 11 | Е:ВПС | ПЕРЕГРІВ ВПУСКУ | tempAirIn > maxAirIn (за замовч. 20°C) |
| 12 | Е:СВЧ | ОБРИВ СВІЧКИ | Струм свічки < Мін.струм через 1 с після ввімкнення (якщо налаштування ≠ 0) |

**Поведінка при аварії:**
- Під час активної роботи → стан **ОХОЛОДЖЕННЯ** (вентилятор продовжує працювати до coolStopTemp)
- Після охолодження → стан **ПОМИЛКА**
- З ВИМКНЕНО або ЗУПИНКИ → одразу **ПОМИЛКА**

Журнал помилок зберігається в EEPROM (кільцевий буфер, до 100 записів). Переглядається на екрані аварій.

## Збірка та прошивка

```bash
# Компіляція
arduino-cli compile --fqbn arduino:avr:mega:cpu=atmega2560 .

# Прошивка
arduino-cli upload -p /dev/cu.usbserial-110 --fqbn arduino:avr:mega:cpu=atmega2560 .
```

Поточний розмір: ~163 KB Flash (64%), ~4.7 KB RAM (57%).
